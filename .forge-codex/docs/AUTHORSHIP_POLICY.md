# Authorship and Metadata Policy

Do not add automated-author credits, generator notices, watermarks, badges, source comments, documentation footers, commit trailers, archive comments, or asset metadata that attributes work to a model, assistant, service, or code-generation tool.

Product terminology describing model orchestration, model providers, or continuity remains valid and must not be removed. This policy concerns authorship attribution, not product functionality.

The package scanner checks common prohibited authorship phrases. A clean scan is a hard completion gate.
