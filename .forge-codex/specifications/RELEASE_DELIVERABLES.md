- repaired native macOS source;
- preserved feature inventory and parity tests;
- project-specific build/run script;
- complete unit/integration/UI/stress tests;
- project memory MCP executable/service and protocol contracts;
- continuity coordinator and durable handoff repository;
- required host plugin kit/native adapter;
- schema migrations and old-version fixtures;
- resource-owner matrix;
- OSLog/signpost instrumentation;
- runtime flow handlers;
- gate handlers and acceptance records;
- sanitizer and Instruments evidence;
- performance results by available memory tier;
- migration and recovery reports;
- host capability report;
- findings resolution ledger;
- final completion report and release handoff.

No placeholder, `fatalError`, commented-out feature, disabled test, or design-only plugin may remain in production paths.
