# Package contents

- `inputs/` — exact current repository, current-state audit, continuity design, E2 design, and original autonomy plan.
- `audit/` — detailed audit, thirty findings, source evidence, build/test evidence, feature matrix, and remediation priority.
- `docs/` — mission, phase playbook, feature preservation, evidence integrity, fail-forward execution, shell protection, native qualification, resource budgets, Qwen execution, local-provider policy, recovery, and research basis.
- `architecture/` — target control plane and subsystem implementation contracts.
- `plans/` — dependency-ordered P00–P14 work packages, G00–G20 gates, finding mappings, feature baseline, source map, budgets, crash matrix, native test matrix, blocker matrix, fixed validator registry, and final qualification order.
- `schemas/` — control-plane, queue, package, reset, evidence, gate, finding-closure, run-state, retention, release-readiness, Qwen slice-plan, invocation-result, and advisory-review contracts.
- `interfaces/` — Swift, XPC, and secure-filesystem interface blueprints.
- `tests/` — detailed qualification specifications for every high-risk subsystem plus Qwen-driver qualification.
- `model/` — the exact Qwen3.8-27B 4-bit execution profile and host-memory budgets.
- `qwen/` — project settings template and one compact context card for each work package.
- `scripts/` — package validation, installation, Qwen/provider preflight, bounded fresh-session driver, publication guard, durable state, evidence capture, immutable gate acceptance, finding closure, release verification, static checks, signing fixtures, and recovery.
- `state/` — restartable initial remediation ledger containing all thirty open findings and all mandatory gates.
- `templates/` — decision, handoff, PR, package, gate, queue, finding closure, and release-attestation examples.
- `evidence/` — source manifest for the included current repository.
