# P14 — Produce a shippable release candidate and stop before shipping

**Priority:** critical
**Depends on:** P13
**Findings:** none
**Gates:** G20

## Objective

Create a locally validated release candidate, source/evidence attestation, and readiness report while performing no publication or distribution action.

## Read only what this slice needs

- `.forge-qwen-state/current-handoff.json`
- `.forge-qwen-remediation/AGENTS.md`
- the mapped findings in `audit/Findings.tsv` and exact source excerpts in `audit/Source-Evidence.md`
- the architecture and test documents relevant to this work package

## Candidate source targets

- `version files`
- `release notes`
- `archive scripts`
- `attestation generator`

## Required deliverables

- release candidate archive
- SBOM or dependency inventory
- release-readiness.json
- signed source/evidence attestation
- known-issues report with no Critical/High entries
- shipped=false marker

## Required focused tests

- all mandatory gates passed
- archive reproducibility check
- Gatekeeper/local launch check
- secret and publication hygiene scan
- do-not-ship guard

## Qwen slice constraints

- Plan first in a fresh read-only session.
- Implement one coherent slice, normally no more than six production files plus focused tests.
- Do not read the entire repository or package into context.
- Do not pass or close a gate from model output.
- Preserve shell access, existing features, project identity, and do-not-ship rules.
- Record command evidence and update the durable handoff.

## Fail-forward rule

Stop with ready_to_ship=false if any mandatory gate is incomplete. Never tag, merge, publish, upload, submit, or distribute.

## Slice stop condition

Stop after one evidence-backed implementation unit and its focused tests, or after a truthful blocker and exact next action have been persisted.
