# Contribution policy

## No outside contributors

**Outside developers are not invited to contribute to this repository.**

This project is maintained solely by the repository owner. There is no open contributor program, no community contribution track, and no accepted path for third-party patches on this remote.

## Use of the software

Anyone may use, copy, modify, and redistribute the software **in accordance with the [Apache License, Version 2.0](LICENSE)**.

If you want to change the software for your own purposes:

1. **Fork** this repository, **or**
2. **Copy** the source into a **new repository** that you own and control.

Do your development, issue tracking, and pull requests **only on your own fork or copy**. Do not submit those changes here.

## Pull requests and issues from outside developers

| Action | Policy |
|--------|--------|
| Pull requests from outside developers | **Not accepted.** No pull request will be approved or merged. |
| Direct pushes or collaborative edits by outside developers | **Not allowed.** |
| Proposed patches, branches, or review requests intended to alter this repository | **Declined.** |

Please do not open pull requests against this repository. They will not be approved.

## Attribution and identity

This repository also enforces a **no AI attribution** rule for commits, authors, branch names, paths, pull request text, comments, and reviews. See [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) and the **No AI Attribution** workflow. That rule is separate from the closed-contributor policy above; both apply.
