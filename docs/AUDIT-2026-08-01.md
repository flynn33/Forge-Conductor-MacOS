# Forge Conductor 0.7.0 release audit — 2026-08-01

## Scope

This audit covers the v0.7 context and agent continuity implementation, its
coexistence with the v0.6 durable-memory surface, the retained `fs_read`
pagination fix, native app/CLI builds, and the macOS UI test target.

The implementation branch was created directly from the freshly fetched
`origin/main` commit `6fe03e0626273ced4211ed4e1bbef8c70cfb36b8` in the
`flynn33/Forge-Conductor-MacOS` repository. No live Forge installation or LM
Studio MCP registration was deployed during development or verification.

## Functional coverage

- Existing stdio MCP exposes all durable-memory and continuity tools.
- Checkpoint/handoff packets persist in SQLite with rebuildable JSON and
  Markdown projections.
- Primary and fallback processes serialize shared-home continuity writes.
- New-chat bootstrap restores task state and preserves open agent snapshots
  until the resumed client reattaches them.
- Agent ownership transfer uses a transactional compare-and-swap update.
- Repeated identical calls soft-handoff on call 4 and hard-block on call 9,
  including denied and failed dispatch paths.
- `continuity/*` pointer notes are hidden from default memory list, search, and
  count results but available with `include_system`.
- `fs_read` supports bounded 1-based line windows, including empty files,
  past-EOF offsets, and `Int.max` lengths without overflow.
- Deployment smoke verification requires both continuity and durable-memory
  product tool sets.
